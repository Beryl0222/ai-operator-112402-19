# 低内存文本换行的稀疏单调输运算子

项目资料使用可独立读写的 JSON。Node.js 22.23.4 下运行 `npm ci --offline` 准备环境，然后运行 `npm run inspect` 检查合成数据字段，运行 `npm test` 校验样本引用及格式。

## 输入契约

每个源/目标有整数容量。运输量为非负整数，源质量可拆，目标容量不可超。源点有 skip 单位费用；锚点给最少运输量。对于任何两条正流边 i→j、k→l，若 i<k 则 j≤l，同一源可拆到多个目标，若同源的实际拆法使光标不能得出唯一目标，保持未确定。候选边费用和锚位在一修订内有效；未加载的折叠区域给候选位置和成本区间，其他资料相同。工作区计内部候选、最优性证据和暂未领取落点。

## 资料读取

样本位于 `inputs/session.json`，其中 `events` 是按到达顺序记下的操作，编号从零开始。open/edit 给出排版修订；check/migrate 查询源词 ID；unfold 提交源、目标下标及真实费用；anchor 设定边与最少量。
